# 公平性与 Rust 价值：对比的第二阶段

## Status

2026-10-22 起草，等所有者确认方向与优先级。规格见 [v02.1](../specs/v02.1-fairness-and-rust-value.md)，计划见 [v02](../plans/v02-fairness-and-rust-value.md)。第一阶段（[v01](v01-credible-benchmark.md)）已完成一次正式运行并发布报告。

## Problem

第一份报告在三件事上站得住：每个被测对象做了同样的工作并经校验，数据可一条命令复现，统计规则事先写明。但它回答不了两个问题，而这两个问题正是所有者和外部读者各自最关心的：

1. 加入 Rust 引擎到底值多少。现在只有一个指标，墙钟。Rust 的收益落在增量更新、CPU、内存、稳定性上，代价落在安装体积、二进制加载、能服务的配置范围上，这些都没有量。
2. 读者凭什么相信对 Tailwind 公平。会被挑的五处：没测开发服务器的增量更新，那是 Tailwind v4 的 Oxide 最擅长的场景；语料和配对表由 TeaCSS 作者单方定义；两边产出的 CSS 体积差 2.6 倍，没说明 Tailwind 多做了什么；Tailwind 用的是 `source(none)` 加显式 `@source`，不是开箱默认；只在一台 Mac 上跑过。

## Proposed direction

在 v01 的协议上加维度，不改已有的测法，让第一份与后续报告可比。按优先级分六项：

| 优先级 | 项 | 回答的问题 |
| --- | --- | --- |
| P1 | dev 层级（开发服务器增量更新）与引擎层的 `incremental` 场景 | 对 Tailwind 最强的场景公平吗；Rust 在 HMR 上值多少 |
| P2 | 引擎层补 CPU 时间、峰值 RSS、生成后堆占用、GC 占比、稳定性；报告加「Rust 的价值」与「Rust 的价格」两张表 | 加入 Rust 的收益和代价各是多少 |
| P3 | 产出量：字节、规则数、声明数，以及每 KB 的耗时 | 体积差 2.6 倍里有多少是 Tailwind 多做的事 |
| P4 | 第二份语料，来源在 Tailwind 一侧：用 Oxide 的 Scanner 从公开的 Tailwind 项目提取类名，按配对表翻译，报告覆盖率 | 语料是不是挑过的 |
| P5 | CI 的 Linux x64 交叉验证运行 | 结论是不是只在一台机器上成立 |
| P6 | 两套配置（开箱默认与文档推荐的生产配置）；PostCSS 集成作为第二种集成 | 配置和集成是不是只选了自己赢的 |

另外两件已做但报告里要前置：方法学在运行前提交并写明提交哈希；每个样本的输出都经校验。它们从「已知限制」挪到报告开头。

## Scope

包含：上表六项的协议、实现与报告结构；规格 v02.1 作为 v01.1 的增补；第二份正式报告在下一个 TeaCSS 版本发布后按新协议运行。

排除：Windows 机器（没有可用硬件，CI 也不提供可信的计时）；Tailwind v3；修改任一被测工具；对 Rust 引擎「覆盖范围」做真实项目配置的普查，只用 teacss-ts 自带的示例配置。

## Rationale

- **先补 dev 层级**：这是唯一一个 Tailwind 可能明显领先而我们没测的场景。先测它，比任何「我们很公平」的声明都有说服力。引擎层的 `incremental` 场景与它共用「在已有语料上追加 K 个类」的生成逻辑，一起做。
- **收益和代价并列**：只报 Rust 快多少，读者会问代价。安装体积（原生包 8.6 MB 对 Oxide 的 2.9 MB）、二进制加载时间、能服务的配置范围，放在同一张表里。
- **产出量而不是归一化**：不把时间除以字节当主指标，因为那会反过来奖励输出臃肿；只并列展示，让读者自己判断。
- **第二份语料来自对方**：配对表仍由我们维护，但类名来源换成 Tailwind 社区的真实项目，翻译规则公开，翻不了的类按比例报告。覆盖率本身就是信息。
- **两套配置都跑**：默认配置对应「开发者照文档装上就用」，生产配置对应「调过的」。两套都报，谁也不能说只挑了一种。

## Open questions

1. dev 层级的「更新完成」判定：以 Vite 的 HMR 更新事件为准，还是以样式表里出现全部新选择器为准。规格采用后者并每 5 ms 轮询一次，更工具无关但有不超过 5 ms 的量化误差。
2. P4 语料的来源项目清单：规格给出选取规则，具体仓库由所有者认可。
3. P6 的 PostCSS 集成是否进第一次 v02 运行，还是作为单独一轮。规格按单独一轮写。
