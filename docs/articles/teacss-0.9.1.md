# TeaCSS 0.9.1：开发服务器快了 30 ms，产物一个字节没变

**结论。** TeaCSS 0.9.1 是一个只改性能的版本，生成的 CSS 与 0.9.0 逐字节相同。在 20 000 个类、300 个文件的项目里：

- 开发服务器里保存一个文件，Rust 引擎从 100 ms 降到 70 ms，TypeScript 引擎从 261 ms 降到 228 ms；
- Vite 生产构建，Rust 引擎从 492 ms 降到 480 ms；
- 引擎本身的生成速度没有变。

对比 Tailwind CSS v4，开发服务器里的差距从 3.2 倍拉大到 4.6 倍（70 ms 对 321 ms）。

## 改了什么

0.9.1 有四项改动，都来自 0.9.0 正式报告之后的[优化卡片](../knowledge/optimization-cards-2026-10-24.md)。每一项发布前都先在「未发布通道」里单独测过：用本地构建与发布版交替运行，各 30 次。

| 改动 | 负责 | 改在哪里 | 单独测得的效果 |
| --- | --- | --- | --- |
| T1 | teacss-ts | 开发服务器默认保留 Vite 的 PostCSS 快速路径，生成的样式表不再每次保存都被 lightningcss 重新解析 | 开发服务器保存 -25 ms |
| T3 | teacss-ts | 字体 URL 改写不再扫描整张样式表 | Vite 构建 -13.5 ms |
| R2 | teacss-rs | 开发服务器每轮不再把全部 20 000 个 token 复制过 NAPI | 开发服务器保存 -5 ms |
| F13.11 | teacss-rs | 缓存命中时复用上次交出的字符串 | 基准里没有这个场景，看不到 |

两张卡片测过之后决定不改：

- T2：20 ms 去抖其实把两次失效合成一次，去掉反而更慢。
- T4：延迟加载日志库只省 3 ms，在噪声之内。

另有一张不改：R1，每个模块一次的 NAPI 调用合起来不到 0.1 ms。耗时在类名提取本身，以后另开卡片。

## 0.9.0 与 0.9.1 并排

同一台机器、同一个 Node、同一套协议，每格 30 次交替运行的中位数，20 000 × 300：

| 场景 | 0.9.0 | 0.9.1 | 变化 |
| --- | --- | --- | --- |
| 开发服务器保存 +10 个类，Rust 引擎 | 100 ms | 70 ms | -30 ms |
| 开发服务器保存 +10 个类，TypeScript 引擎 | 261 ms | 228 ms | -33 ms |
| 开发服务器保存 +10 个类，Tailwind（对照） | 322 ms | 321 ms | 不变 |
| Vite 构建，Rust 引擎 | 492 ms | 480 ms | -12 ms |
| Vite 构建，Tailwind（对照） | 791 ms | 810 ms | +18 ms |
| 引擎生成，Rust 引擎 | 52 ms | 51 ms | 不变 |

两边的单独测量加起来是 -25 加 -5，正好就是开发服务器的 -30 ms。T1 自己的目标是 70 ms 以内，它单独只到 77.7 ms，加上 R2 后达到 70.1 ms。

Tailwind 的构建这次慢了 18 ms，其他构建工具上两边也多了 5 到 24 ms：这一天机器整体慢了约 2%。所以 Rust 引擎的 Vite 构建实际省下的，比表里的 12 ms 略多。

## 对 TeaCSS 仍然不利的地方

- **小项目构建。** 1 000 个类时，15 张构建表里：
  - Tailwind 在 8 张里可测地更快，领先 6 到 25 ms；
  - 7 张无可测差异，其中 5 张 TeaCSS 的中位数更低。

  0.9.0 时 Tailwind 在 15 张里中位数都最低，10 张可测。
- **TypeScript 引擎的构建仍比 Tailwind 慢。** 45 组构建比较里 42 组更慢，另 3 组都在 Rsbuild、20 000 个类，无可测差异。
- **引擎只占构建的一小部分。** Rust 引擎生成只要 51 ms，Vite 构建里 CSS 一共加 245 ms，引擎占 21%。剩下的是插件流水线和类名提取。

## 公平性

方法与 0.9.0 那一轮相同，细节见那两篇文章的「怎么测的」与「怎么保证公平」：

- 发布版、Node 24.14.1；
- 计时前逐类校验，78 000 个用例零差异；
- 所有对象逐轮随机交替，每格 30 次；
- 负载连续两分钟低于 2.4 才开始，各格负载份额 21% 到 37%；
- 构建计时到构建返回为止。

117 组 Rust 引擎与 Tailwind 的正面比较：TeaCSS 赢 102 组，Tailwind 赢 8 组，7 组无可测差异。Rust 引擎与 TypeScript 引擎的 117 组比较，Rust 全胜，3 510 对样本产出逐字节相同。

限制不变：

- 只有一台 Apple M2 Max，Linux 交叉验证未跑；
- 只有生成的配对语料，社区语料还在等仓库清单；
- 本基准的作者也开发 TeaCSS。
